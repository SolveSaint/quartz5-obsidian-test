# quartz5-obsidian-test

This is a Quartz 5 test site for verifying an Obsidian-style publishing workflow on GitHub Pages.

## Site identity

- Live site: https://solvesaint.github.io/quartz5-obsidian-test/
- Repository: https://github.com/SolveSaint/quartz5-obsidian-test
- Site title: `quartz5-obsidian-test`

## Editing notes

Edit Markdown source files in the `content/` directory. The homepage source is `content/index.md`.

## Publishing notes

Changes pushed to the `main` branch are built by GitHub Actions and published through GitHub Pages.

## Basic frontmatter

Use ordinary YAML frontmatter at the top of notes:

```yaml
---
title: Example note
---
```

## Content instructions

Keep public content focused on site-owner information and visible site content. Do not publish internal operator instructions, private deployment rules, or assistant workflow notes on this homepage.
